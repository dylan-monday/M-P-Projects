What this is

A report you can read, and a report you can talk to.

03
Scope of Work

Four phases.

Phase 01 Print report

Design the printed report, cover to cover.

The ~30–45 page statewide startup report with a visual identity and design system, data viz, and generative art illustrations. Handoff as a digital PDF and a print-ready package if you decide to print.

  • Visual system: type, color, chart styles, generative-art integration
  • Design using custom generative illustration
  • Interior layout: section openers, data pages, regional breakdowns, methodology, appendix
  • Custom data visualizations matched to the aesthetic
  • Custom generative-art assets produced for cover and section openers
  • Production-ready print files
  • Up to three rounds of revision
Phase 02 Web editorial design

Translate the report into a web experience.

Art direction, motion design, and editorial layout for the web version. This is where the print aesthetic becomes kinetic, and where the report's ten key findings each get their own signature treatment.

  • Web art direction: typography at screen scale, color in motion, responsive editorial grid
  • Animated generative backgrounds
  • Design of section openers, scroll-triggered transitions, and data-visualization motion
  • Responsive design across desktop, tablet, and mobile
  • Up to three rounds of design revision
Phase 03 Web build + AI

Build the site, ship the assistant.

Engineering the web report end-to-end and adding the piece that makes it different from every other report: a chatbot that can answer questions about the dataset with a cited, accurate answer, often with a chart.

  • Responsive web app built on Next.js, deployed to Vercel
  • All report content in navigable sections, with PDF one click away
  • Implementation of the Key Findings motion treatments designed in Phase 02
  • Typed query tools for exploring the dataset (capabilities confirmed after data review)
  • Claude API integration with a tool-calling loop and a custom system prompt for voice and citation
  • Streaming chat UI matched to the design language, with a terms gate and per-session query limit
  • On-the-fly chart generation rendered to a high-resolution canvas, scaled responsively across devices, with attribution baked in and per-chart data download so users can pull the underlying numbers
  • Privacy and accuracy guardrails: minimum cell size enforced at the tool layer, denominators always cited, no re-identification
  • Lightweight CMS integration (Decap): a Git-based admin UI for editing report copy, findings text, metadata, the AI system prompt, and an AI kill switch (no redeploy needed)
  • Auth-gated admin and analytics dashboard: real-time visibility into usage, AI costs, token consumption, error rates, and query patterns
Phase 04 Production hardening

Ship it like you mean it.

The work that turns a prototype into a public-facing product. Accessibility, performance, observability, and the kind of small refinements that readers feel but don't see.

  • Accessibility pass: keyboard navigation, screen-reader semantics, color contrast, reduced-motion support
  • Performance tuning: bundle optimization, image compression, page-speed targets, and edge caching
  • SEO and social: Open Graph, Twitter cards, sitemap, structured data for the report and findings
  • Analytics + error monitoring (Vercel Analytics, Sentry or equivalent) with dashboards you can read
  • Chatbot observability: token usage, query logging, rate-limit tuning, cost alerting
  • Testing across Safari, Chrome, Firefox, and Edge; real-device QA on iOS and Android
  • Go-live checklist, a documented plan for handling issues post-launch, and a complete project handoff package
04
How the chatbot works

Plain English in. Sourced answers out.

No fabrication. No free-wheeling. The assistant queries the actual dataset and reports what it finds.

Rather than a retrieval-augmented search pipeline, the assistant uses tool calling. Claude is given a set of typed functions (count respondents, get a distribution, run a crosstab, compute numeric stats) and chooses which to call to answer each question. The data never leaves a structured JSON dataset.

Every answer cites its base count. A minimum cell size (threshold to be confirmed) is enforced at the tool layer, not just in the prompt, so small-sample claims are suppressed before they can be written. If a chart is the clearest answer, one is rendered on a canvas with attribution baked in. Anything out of scope is declined, not guessed.

Step 01

Reader asks

"How does revenue growth compare across regions?" Typed in plain English, no filters or dashboards.

Step 02

Claude picks a tool

From the typed toolset (distribution, crosstab, numeric stats, funding gap, revenue trajectory), Claude selects the right one and runs it against the dataset.

Step 03

Answer with a base

Claude writes a grounded reply in the report's voice, always citing the denominator ("69% of the 93 respondents who answered").

Step 04

Visualize

When useful, a bar, horizontal-bar, donut, or stacked chart renders to a high-resolution canvas, downloadable at deck-ready resolution, with attribution.

05
Technology

Lean stack. No lock-in.

Everything below is industry-standard, well-documented, and easy to hand off. We manage the accounts through year one; at renewal, ownership can transfer to Tulane or LA.IO with no rebuild.

Frontend & hosting

Next.js
React framework for the report pages and the chatbot's API routes.
Vercel
Global CDN, serverless functions, zero-config deploys.

AI & data

Claude Sonnet
Answers questions via a tool-calling loop, capped at 10 tool calls per query and 8 turns of history.
Typed query tools
Query tools for dataset exploration, with a minimum cell size (threshold to be confirmed) enforced in code.
Static JSON dataset
The cleaned survey lives as a single JSON file. No database, no vector store, no embeddings. Simple to audit, easy to update year-over-year.

Charts

Canvas API renderer
Custom renderer. No Chart.js, no D3. Four types: bar, horizontal bar, donut, stacked. Deck-ready PNG out.
Attribution baked in
Every chart carries Tulane Freeman · Albert Lepage Center · LA.IO and Louisiana Startup Report 2026.
